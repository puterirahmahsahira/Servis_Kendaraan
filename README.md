# servis_kendaraan
Project UAS - Aplikasi Servis Kendaraan - Tim CALON CEO

Aplikasi manajemen dan sistem pencatatan servis kendaraan berbasis Java.

## Fitur Utama (Dalam Pengembangan)
- Manajemen Data Pelanggan
- Pendataan Kendaraan
- Layanan & Perbaikan Servis
- Estimasi dan Penghitungan Biaya Servis

## Kebutuhan Sistem
- Java Development Kit (JDK) 21 atau lebih baru
- IntelliJ IDEA / IDE Java lainnya
